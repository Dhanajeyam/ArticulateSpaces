ARTICULATE SPACES WEBSITE — VS CODE PROJECT

FILES
- index.html             : page content and website structure
- style.css              : colours, typography, spacing, layout and responsive design
- script.js              : mobile menu and Google Sheets enquiry form integration
- google-apps-script.js  : ready-to-use Google Apps Script to save enquiries to Google Sheets
- GOOGLE_SHEETS_SETUP.md : step-by-step 2-minute guide to connect forms to Google Sheets

PREVIEW
1. Open this folder in Visual Studio Code.
2. For easiest preview, install the "Live Server" extension in VS Code.
3. Right-click index.html and choose "Open with Live Server".

GOOGLE SHEETS SETUP
- Follow GOOGLE_SHEETS_SETUP.md or the comments in google-apps-script.js.
- Paste your deployed Apps Script Web App URL into GOOGLE_SHEET_SCRIPT_URL in script.js.

BEFORE PUBLISHING
- Replace the text-based AS placeholder with your original, unchanged company logo.
- Replace stock photos with project images you own or have permission to publish.
- In script.js, ensure GOOGLE_SHEET_SCRIPT_URL has your live Web App URL.
- Review all business claims, contact details and service descriptions.
